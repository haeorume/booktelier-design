## 1. 원칙

1. **지면이 주인공이에요.** 가운데는 언제나 종이책 판형 지면이고, 둘레의 도구는 엷은 회색으로 조용히 둬요.
2. **셋이 같은 지면 하나를 봐요.** 역할마다 다른 화면을 만들지 않고, 같은 화면에서 보이는 도구와 패널만 달라요(UX PR-15). 시안의 원고 편집·조판 전환은 조판 설정 패널을 여닫는 단추예요.
3. **색은 뜻이 있을 때만, 글자나 모양과 함께.** 역할은 머리글자와 이름, 제안 종류는 선 모양, 상태는 낱말을 함께 써요(WCAG 1.4.1).
4. **주황은 아껴 써요.** 주요 버튼(주황 바탕)은 화면에 하나. 켜짐·지금 장·선택은 엷은 주황(`--bt-accent-soft`) + 주황 점·선.
5. **시안 크기를 지켜요.** 화면 글자는 시안대로 8~13px이에요(V-01). 지면 본문만 조판 값(pt)을 따라요.

## 2. 토큰

값은 `tokens.css`(밝게)와 `tokens-dark.css`(어둡게, 두 곳: 컴퓨터 설정 · `data-theme="dark"`)에만 있어요. 컴포넌트 CSS(`*.module.css`)는 `var(--bt-…)`만 쓰고 색 값을 직접 쓰지 않아요(R11). 새 이름이 필요하면 두 파일에 같이 더해요.

## 4. 지면과 미리보기

### 작업 지면(한 쪽 보기, FR-17)
- 종이: `--bt-paper`, `--bt-shadow-paper`, 모서리 0. 책상 위 24px, 아래 38px, 좌우 27px.
- 지면 머리(시안 `.running-title`): 위 여백 가운데 높이에 8px 흐린 글자로 왼쪽 책 제목, 오른쪽 BOOKTELIER. 흐름 밖에 놓아 쪽 나누기에 끼지 않아요.
- 장 머리: `CHAPTER 01`(9px, 자간 0.2em, `--bt-paper-kicker`) → 장 제목(화면 글꼴 28px 600, `--bt-paper-title`) → 28×2px 주황 선(`--bt-accent-rule`). 미리보기(`domain/preview.ts`)의 장 머리도 같은 크기라 작업 지면의 쪽 경계와 미리보기의 쪽 나누기가 같아요.
- 여백 안내선: 본문 단 둘레 1px `--bt-guide-line` + 네 모서리 6px 네모(`--bt-guide-corner`). 메뉴 '보기 › 조판 안내선'으로 끄고 켜요.
- 쪽 경계·쪽 번호·머리말은 v0.1 그대로(PageGuides).
- 본문: 글꼴·크기·행간·여백은 조판 설정 값(`domain/templates.ts`).
- 지면 아래 글귀: '문장에 집중하는 시간'(9px)과 양쪽 짧은 선.

## 7. 시안에서 아직 빠진 것

오름님 시안은 **지향하는 시스템**(기능과 경험의 목표)이에요. 아래는 모양만 있거나 빠진 것이라, 만들 때는 지금 구조(웹 Next.js → REST·폴링 → FastAPI 서버의 AI 계층 → PostgreSQL·pgvector, 외부 LLM·임베딩 API)를 그대로 따르고 서버 API부터 정해요(D-25).

- 북엔드 로고·글자·책 표지 사진(R4·R10). 북엔드 허락 뒤에 넣어요.
- 글자 서식·표·이미지 넣기의 실제 동작(D-13). 단추 모양만 있어요.
- **협업 일정(홈 일정 상자·일정 단추·알림)은 화면에서 아예 뺐어요(11.22 오름님 결정).** 원본 저장소에 일정 기능(테이블·API·요구사항)이 없어서예요. 넣으려면 DB 테이블 → 서버 API → data/ 어댑터 → 화면 순서로 따로 만들어요.
- 원고 구조의 부(部) 묶음, '자료' 탭 내용, 시연용 안내 띠(`.bf-demo-rail`), 시연 알림 토스트.
- 시안의 hover로 작업 바꾸기 움직임(520ms 스프링). 짧은 움직임(180ms)만 써요.
