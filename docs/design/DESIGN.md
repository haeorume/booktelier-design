| 항목 | 내용 |
| --- | --- |
| 넣을 자리 | `docs/design/DESIGN.md`(이 문서), `web/src/styles/tokens.css`(색·글자·간격 값), `docs/design/specimen.html`(토큰으로 그린 작업 공간 견본. 1440·1280px에서 확인) |
| 출처 | 오름님 HTML 프로토타입 11.19 판(CSS 변수와 화면), UX 설계서 v0.4(화면 목록·레이블·상태), 요구사항 v0.4, 최종 MVP 간극 논의판 rev 7 |
| 상태 | 2026.11.20 Claude 초안, 혜린 확인 전. 오름님 갱신 디자인 가이드가 오면 **값은 그쪽을 따르고 이 문서와 `tokens.css`를 고쳐요** |

## 1. 원칙

1. **지면이 주인공이에요.** 화면 가운데는 언제나 종이책 판형 지면이고, 도구는 둘레에 조용히 둬요. 시안의 메뉴 막대·서식 막대는 두지 않아요(7장).
2. **셋이 같은 지면 하나를 봐요.** 역할마다 다른 화면(Edit·Layout)을 만들지 않고, 같은 화면에서 보이는 도구와 패널만 달라요(UX PR-15).
3. **색은 뜻이 있을 때만 쓰고, 늘 글자나 모양을 같이 써요.** 역할은 배지 글자, 제안 종류는 선 모양, 상태는 낱말을 함께 써요(WCAG 1.4.1).
4. **주황은 아껴 써요.** 화면 하나에 주요 버튼(주황 바탕)은 하나예요. 밝은 주황(`--bt-brand`)은 로고·포커스·선택 선에만 쓰고 글자에는 쓰지 않아요.
5. **읽을 수 있어야 해요.** 화면 글자는 12px 이상, 글자 대비 4.5:1, 테두리·아이콘 3:1 이상이에요. 시안의 7~11px 글자와 흐린 회색 글자는 올리거나 진하게 바꿨어요(UX PR-13).

## 2. 토큰

값은 `tokens.css` 하나에만 있어요. 컴포넌트 CSS(`*.module.css`)는 `var(--bt-…)`만 쓰고 색 값(#…, rgb)을 직접 쓰지 않아요(하네스 불변 규칙 R11).

| 묶음 | 쓰는 곳 | 대표 값 |
| --- | --- | --- |
| 바탕 | 책상 `--bt-bg`, 면 `--bt-surface`, 패널 `--bt-panel`, 종이 `--bt-paper` | #F5F7FA, #FFF, #FAFBFD, #FFFDF7 |
| 글자 | 제목 `--bt-ink`, 본문 `--bt-text`, 보조 `--bt-text-2`, 흐림 `--bt-text-3` | #24354B, #27303D, #5F6B7A, #667284 |
| 동작 | 주요 버튼 `--bt-action`(흰 글자), 주황 글자 `--bt-accent-text`, 포커스 `--bt-brand` | #B94A13, #AB4310, #EC661F |
| 역할 | 편집자 주황, 작가 파랑, 디자이너 보라(바탕·테두리·글자 세 벌) | 시안 값, 글자만 진하게 |
| 종류 | 맞춤법 빨강 물결, 띄어쓰기 주황 겹선, 표기 통일 파랑 굵은 점선, 윤문 청록 띠 | 1차 코드 밑줄과 같음 |
| 사람 표시 | 수정 제안 보라(취소선·파선), 의견 노랑 칠·점선 | #7C4DCC, #A16207 |
| 글꼴 | 화면 Noto Sans KR, 명조 본문 Georgia + Noto Serif KR, 고딕 본문 Noto Sans KR | 모두 OFL(상업 이용 가능) |
| 크기 | 12 · 13 · 14 · 16 · 20 · 28px. 굵기 400 · 500 · 600 | 시안 650·700은 600으로 |
| 간격 | 4px 단위(4, 8, 12, 16, 20, 24, 32, 48) | |
| 모서리 | 칩 4, 버튼·입력 6, 카드 8, 창 12 | 시안 2~11px를 넷으로 묶음 |
| 그림자 | 작음, 보통, 창·팝오버, 지면 | 시안 값 그대로 |

글꼴은 `next/font/google`로 Noto Sans KR·Noto Serif KR를 불러요(파일을 저장소에 넣지 않음). Pretendard는 쓰지 않아요(라이선스 확인을 줄이려고. 1차 코드의 `globals.css`에 남은 이름은 지워요).

## 3. 작업 공간 배치

1440×900 기준이에요. 1280px에서도 겹치거나 잘리지 않아야 해요(QA-F29와 1차 QA-49).

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 상단 바 56px                                                                  │
│ BOOKTELIER │ 편집자 홈 › 책 › 장 [역할 배지] │ 장 상태·검토 요청 │ (아바타들) 저장됨 │
│            │                                 │ 미리보기  검토본  초대  조판 설정  ▢ │
├──────────────────────────────────────────────────────────────────────────────┤
│ 장 탭 줄 40px  [1장 아주 작은 시작 ×] [2장 여백에 남은 마음 ×]        (Could)  │
├────────────┬─────────────────────────────────────────────┬───────────────────┤
│ 원고 구조   │ 지면 도구 줄 36px: 보기 [의견][AI 밑줄][수정 제안][안내선]   │ 검토 패널 340px   │
│ 224px      ├─────────────────────────────────────────────┤ [내 AI 제안][함께 │
│ 장 목록     │ 책상(--bt-bg)                                │  봄][AI 대화]     │
│ + 장 추가   │   ┌───────────── 지면(--bt-paper) ─────────┐ │ 장 검토 · 거르기  │
│            │   │ 머리말          쪽 번호                 │ │ 카드 목록         │
│            │   │ 본문 …                                 │ │                   │
│            │   └─────────────────────────────────────────┘ │                   │
│            │   ─ ─ ─ 쪽 경계 ─ ─ ─  (한 쪽 보기)           │                   │
└────────────┴─────────────────────────────────────────────┴───────────────────┘
```

- **상단 바 항목 순서**(왼쪽부터): 로고, 경로(UX WS-11), 역할 배지(WS-12), 장 상태와 검토 요청·검토 완료 버튼(WS-31을 상단 바로 올림. 시안 배치), 오른쪽에 접속자 아바타(WS-13), 저장 상태(WS-14), 미리보기(WS-15), 검토본(WS-03), 초대(WS-02, 편집자만), 조판 설정(WS-04), 오른쪽 패널 접기. 권한이 없는 버튼은 숨겨요(D-15).
- **오른쪽 패널**: 검토 패널과 조판 설정. 하나씩(A안, 기본)과 나란히(B안)는 1차 비교 결과로 정해요(UX N-15, 확인할 것 23). 1280px에서 나란히 열면 원고 구조를 56px 아이콘 줄로 접어요(잠정).
- **지면 도구 줄**: 시안의 서식 막대 두 줄 자리를 '보기 켜고 끄기'(FR-52) 한 줄로 바꿔요. 굵게·기울임은 이 줄이 아니라 선택 메뉴(WS-35)에 둬요(작가만).
- **상태 줄**(시안 맨 아래 'Edit · 124자 · 100%'): 두지 않아요. 글자 수가 필요하면 원고 구조 아래에 작게.

## 4. 지면과 미리보기

### 작업 지면(한 쪽 보기, FR-17)
- 판형 폭(mm)의 종이 한 장이 이어지고, 쪽이 넘어가는 자리에 **쪽 경계 선**(1px 파선 `--bt-line-control`)과 **쪽 번호**(바깥쪽 아래, 12px `--bt-text-3`)가 보여요. 원고가 바뀌면 '반영 중'(L-43)이 지면 오른쪽 위에 작게 떠요.
- 종이: `--bt-paper` 바탕, `--bt-shadow-paper`, 모서리 0. 둘레 책상 여백 `--bt-desk-gutter`.
- 머리말: 왼쪽에 책 제목, 오른쪽에 장 제목(12px `--bt-text-3`). 쪽 공통 설정(FR-44)이 정해요.
- 장 머리(시안): 눈썹 글자 `CHAPTER 01`(12px, `--bt-accent-text`, 자간 `--bt-tracking-eyebrow`) → 장 제목(본문 글꼴, 본문의 1.6배) → 주황 짧은 선(24px × 1px `--bt-brand`). 영문 눈썹 글자는 지면 장 머리에만 쓰고, 화면 안내 글은 한글이에요.
- 본문: 글꼴·크기·행간·여백은 조판 설정 값을 CSS 변수로(`domain/layout.ts`). 안쪽·바깥쪽 여백은 한 쪽 보기에서 홀수 쪽 기준(안쪽이 왼쪽)으로 보여요.
- 검토 표시(밑줄, 수정 제안, 의견)는 `tokens.css`의 종류·사람 표시 색과 선 모양을 따라요(UX CS-11). 지면 여백의 의견 아바타는 시안 그대로(지름 24px, 역할 색 세 벌).

### 템플릿 잠정값(오름님 값이 오기 전, 요구사항 Q-24)

화면 확인용으로 정한 값이라 실무 기준이 아니에요. 오름님 값이 오면 바꿔요.

| 템플릿 | 판형(mm) | 여백 위·아래·안쪽·바깥쪽(mm) | 제본 여백(mm) | 본문 | 크기 | 행간 |
| --- | --- | --- | --- | --- | --- | --- |
| 소설 | 46판 127×188 | 18 · 20 · 17 · 14 | 3 | 명조 | 10pt | 1.75 |
| 에세이 | 국판(A5) 148×210 | 20 · 22 · 20 · 16 | 3 | 명조 | 10.5pt | 1.8 |
| 실용서 | 신국판 152×225 | 20 · 20 · 18 · 16 | 3 | 고딕 | 10pt | 1.65 |

1차 코드(`domain/templates.ts`)의 판형 128×188·130×200과 여백 한 값(`margin`)은 이 표로 바꿔요(저장된 책의 값 옮기기는 하네스 F2).

### 미리보기(PV-01~05, FR-43)
- 상단: 돌아가기(왼쪽), 장 이름과 쪽 범위, 보기 켜고 끄기(처음엔 모두 꺼짐), 쪽 넘기기(아래 가운데).
- 펼침면: 책상(`--bt-soft`) 위에 왼쪽·오른쪽 쪽을 붙여 놓고, 가운데 접히는 자리에 안쪽 그림자(양쪽 12px 그라데이션)를 둬요. 쪽 번호는 바깥쪽 아래, 머리말은 쪽 공통 설정대로 왼쪽·오른쪽을 달리해요. 안쪽 여백 + 제본 여백이 접히는 쪽에 붙어요.
- 그리기: Paged.js(CSS Paged Media)로 같은 CSS를 써요. 인쇄용 PDF를 나중에 붙일 때도 이 CSS를 그대로 써요.
- 읽기 전용이에요. 커서, 선택 메뉴, 카드 버튼이 없어요.

## 6. 화면별 기준

| 화면 | 시안에서 가져오는 것 | 바꾸는 것 | 빼는 것 |

## 7. 시안에서 빼는 것

이유는 UX 설계서 '프로토타입 검토'와 논의판에 있어요.

- 'BOOKEND STUDIO' 로고와 '북엔드' 글자 → BOOKTELIER 글자 로고(PR-26, D-01, 불변 규칙 R4). 북엔드 심볼은 북엔드 허락 뒤.
- Edit·Layout 전환과 Layout 도구(도형·펜·자유 배치)(PR-15).
- 글자마다 주는 서식 도구(색·형광펜·밑줄·취소선·글자 단위 글꼴·크기), 표, 이미지(PR-16).
- 떠 있는 AI 창, AI 버튼, AI 칩(PR-17). AI 대화는 검토 패널 셋째 탭만.
- AI 제안 종류 교정·교열·조판 점검(PR-27), 카드 '보류'(PR-19), 역할 바꾸는 선택 칸(PR-20), AI 켜고 끄기(PR-23).
- 파일 저장·원고 가져오기(PR-22), 팀 대화(PR-25), 시연용 안내 띠(`.bf-demo-rail`).

## 8. 확인하는 법

- 기계: 불변 규칙 R11(컴포넌트 CSS의 색 값 직접 쓰기), R4('북엔드' 표기). e2e에 접근성 검사(axe)를 붙이면 대비·이름 없는 버튼을 잡아요(하네스 F7, 선택).
