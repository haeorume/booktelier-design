## 기획서 핵심 기능과의 대응

| 기획서 III의 기능 | 기획서 우선순위 | 요구사항 |
| --- | --- | --- |
| 원고·조판 동시 편집 화면 | Must | FR-09 (1차: 템플릿을 입힌 편집 화면), FR-17 (2차: 쪽을 나눈 지면) |
| 실시간 공동 작업 | Must | FR-18, FR-19, NFR-08. 1차는 FR-41로 대신 보여 준다 |
| 조판 화면 위 코멘트·수정 제안 | Must | FR-32, FR-33, FR-34, FR-35, FR-36 |
| 조판 템플릿 적용 | Must | FR-10, FR-16 (1차에 디자이너와 편집자가 조판 설정을 바꾼다) |
| 버전 기록 | Should | FR-38 (검토본 저장), FR-37 (변경 이력). 이전 상태와 비교는 요구사항으로 올리지 않았다 |
| 챕터 단위 공유·권한 | Should | 요구사항으로 올리지 않았다. 공유와 권한은 책 단위다(FR-05, NFR-01) |
| 기획 단 보조 기능 | Could | 요구사항으로 올리지 않았다. 화면정의서에만 남긴다 |
| AI 제안(FR-20~FR-31)은 기획서 III에 없다. 11.14 요청서와 11.16 회의에서 더해진 범위다. 디자이너 역할(FR-42)은 기획서 II의 열린 질문(북 디자이너를 별도 사용자로 볼지)에 대한 11.18 결정으로 더해졌다. |  |  |
