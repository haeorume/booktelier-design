## 경계 합의용 문서 (11.15)

북틀리에 UX 설계서 v0.4. 화면 ID는 이 문서의 '2 IA' 탭과 같다

D1~D8은 「AI 범위 합의와 역할별 요청」(11.14)의 항목 번호이고, 회의록의 '관련' 칸에 적힌 대로 옮겼다

11.18 혜린 결정(디자이너 역할, 셋이 한 ePub 화면에서 작업)과 오름님 HTML 프로토타입(11.17) 검토

최종 MVP 간극 논의판(11.20, rev 7). 'HTML 표 n'은 오름님 HTML과 11.18 결정이 부딪히는 표의 n번 줄, '가져올 것 n'은 가져오면 좋은 것의 n번

## 표기

| 칸 | 값 | 뜻 |
| --- | --- | --- |
| ID | FR-nn | 기능 요구사항 |
|  | NFR-nn | 비기능 요구사항 |
| 우선순위 | Must | 없으면 핵심 흐름이나 핵심 가치가 성립하지 않는다. 기획서 Must 기능, 핵심 흐름 단계, 회의록 '끝까지 지킬 것' |
|  | Should | 중요하지만 없어도 핵심 흐름은 끝난다 |
|  | Could | 시간이 남으면 넣는다. 회의록 '밀리면 빼는 순서' |
|  | (Won't) | 이번에 하지 않는 것. '하지 않는 것' 탭에 따로 적었다 |
| 릴리스 | 1차 | 11.18(수) 1차 MVP. 최종 MVP에도 그대로 들어간다 |
|  | 2차 | 최종 MVP(11.26)에 새로 넣는 것 |
| 수용 여부 | 수용 | 회의록에 합의나 결정으로 적힌 것 |
|  | 보류 | 정모님 검토 대기. 추천안을 잠정값으로 썼다 |
|  | 미검토 | 회의에서 다루지 않은 것. 작성자 제안이다 |
| 출처 | 데모 n | 데모 플로우(퍼널)의 n단계 |
|  | 결론 n | 회의록 '1. 전달'의 벤치마킹 결론 n |
|  | 은미 11.14 | 기획서 코멘트 백업의 은미님 11.14 논의용 코멘트 |
| 비고 | Q-nn | 미결 사항' 탭의 번호 |
