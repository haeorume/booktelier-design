## 표기

| 칸 | 값 | 뜻 |
| --- | --- | --- |
| ID | FR-nn | 기능 요구사항 |
|  | NFR-nn | 비기능 요구사항 |
| 우선순위 | Must | 없으면 데모 플로우나 핵심 가치가 성립하지 않는다. 기획서 Must 기능, 데모 플로우 단계, 회의록 '끝까지 지킬 것' |
|  | Should | 중요하지만 없어도 데모 플로우는 끝난다 |
|  | Could | 시간이 남으면 넣는다. 회의록 '밀리면 빼는 순서' |
|  | (Won't) | 이번에 하지 않는 것. '하지 않는 것' 탭에 따로 적었다 |
| 릴리스 | 1차 | 11.18(수) 1차 MVP |
|  | 2차 | 목요일 이후 최종 MVP |
| 수용 여부 | 수용 | 회의록에 합의나 결정으로 적힌 것 |
|  | 보류 | 정모님 검토 대기. 추천안을 잠정값으로 썼다 |
|  | 미검토 | 회의에서 다루지 않은 것. 작성자 제안이다 |
| 출처 | 데모 n | 데모 플로우(퍼널)의 n단계 |
