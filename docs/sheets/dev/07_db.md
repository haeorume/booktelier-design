# 개발 문서 · db

> 원본은 Google 시트 '개발 문서'의 'db' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

2차(최종 MVP)에서 서버가 데이터를 DB에 어떻게 저장하는지예요. 필드 하나하나(뜻, 타입, DB 타입, 키)는 data-contract '4. 필드'에 있고, 이 탭에는 여러 테이블에 걸친 것만 적었어요. 저장소, 테이블 목록, 키와 색인, RAG 자료, KPI가 쓰는 칸이에요. 잠정값은 DB 설계 초안(11.19)과 11.20 RAG 논의에서 왔어요. 노란 칸은 정모님이 확정하는 칸이에요. 코드를 짜기 시작하면 Pydantic·DB 모델이 원본이 되고, 이 탭은 합의한 내용을 남기는 곳이에요.
