# 개발 문서 · routes

> 원본은 Google 시트 '개발 문서'의 'routes' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

화면마다의 주소와, 누가 어디로 들어오는지를 적었어요. 화면 ID와 화면에 담기는 것은 UX 설계서 '2 IA' 탭이 원본이고, 여기에는 주소와 들어오는 조건만 있어요. 주소는 회의록의 초안을 그대로 썼어요.

## 3. 주소 규칙

| 번호 | 규칙 | 근거 | 내용 |
| --- | --- | --- | --- |
| 1 | ID | 충돌 방지 규칙 2 | projectId와 chapterId는 브라우저에서 UUID로 만들고 서버가 형식과 중복을 확인한다. 서버를 붙여도 바꾸지 않는다 |
| 2 | 주소에 넣는 것 | N-13 | 책과 장만 넣는다. 열린 창, 검토 패널의 탭, 필터는 주소에 넣지 않는다 |
| 3 | 뒤로 가기 | N-13 | 장을 옮긴 것은 기록에 남고, 창·탭·필터를 바꾼 것은 남지 않는다 |
| 4 | 장 옮기기 | N-05 | 장 목록에서 장을 누르면 chapterId만 바뀐다. 검토 패널에서 보던 탭은 그대로 둔다 |
| 5 | 링크 미리보기 | 하네스 체크리스트 | /j/[token]에 OG 태그를 넣어 메신저로 보낼 때 미리보기가 뜨게 한다 |
| 6 | 토큰 | 리뷰 B-2·B-3, NFR-13 | 편집자 토큰과 참여자 토큰은 서버가 발급하고 브라우저 저장소에 둔다. API 요청마다 헤더로 보낸다(api-needs 1번). /e/[token]·/j/[token]으로 들어온 뒤에는 주소에서 토큰을 지워(replace) 방문 기록과 화면 공유에 남지 않게 한다 |
| 7 | 미리보기 | FR-43, 11.19 팀 회의 | 지금 장 주소 뒤에 /preview를 붙인다. 새 탭으로 열어 작업 공간과 나란히 볼 수 있다. 읽기 전용이라 원고를 고치는 API를 부르지 않는다 |
| 8 | 개발용 막대 | FR-41, 리뷰 R-7 | 기본으로 꺼져 있고, 데모·테스트 모드 환경 변수가 켜진 배포에서만 보인다. 최종 배포에서는 꺼진다 |
| 9 | 장 탭 | FR-48 | 열어 둔 장 탭 목록은 주소에 넣지 않고 사람마다 브라우저에 둔다. 탭을 누르면 chapterId만 바뀐다(규칙 4) |
