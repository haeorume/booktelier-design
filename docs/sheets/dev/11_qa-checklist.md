# 개발 문서 · 1차 점검

> 원본은 Google 시트 '개발 문서'의 '1차 점검' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

1차 MVP 결과를 받으면 위에서부터 눌러 보며 '결과'를 고르는 표예요. QA-01~18이 관문(시작 전 확인과 데모 13단계)이고, 그 아래는 13단계 밖에서 1차에 들어가는 것들이에요. '일부'나 '안 됨'이면 메모에 무엇이 달랐는지 적고 고칠 곳(코드, 문서, 결정 필요)을 골라요. 근거에 '잠정'이 붙은 줄은 아직 확정 전 값이라, 결과가 달라도 버그가 아니라 결정 거리일 수 있어요. 하네스 입력 문서가 아니라 결과 확인용이에요. 11.18 15시 문서 기준, 혜린 초안.
