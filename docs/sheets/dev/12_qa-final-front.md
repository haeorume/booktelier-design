# 개발 문서 · 최종 점검(프론트)

> 원본은 Google 시트 '개발 문서'의 '최종 점검(프론트)' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

최종 MVP를 배포 주소에서 눌러 보며 '결과'를 고르는 표예요(혜린 초안 11.20). 화면에서 확인할 수 있는 것만 담았고, 서버·DB·AI 점검은 정모님 표에 따로 둡니다. 세 역할을 서로 다른 브라우저(또는 컴퓨터)로 열고 해요. Could 줄(QA-F25~27)은 넣은 경우에만 봐요. '일부'나 '안 됨'이면 메모에 무엇이 달랐는지 적고 고칠 곳(코드, 문서, 결정 필요)을 골라요.
