## 3. 내비게이션 설계

사용자가 화면 사이와 화면 안에서 움직이는 길이에요. 들어오는 길, 전체 내비게이션, 화면 안 내비게이션, 맥락 내비게이션, 도구, 규칙으로 나눴어요. 원고까지 누르는 횟수는 편집자 1번, 초대받은 사람 0번이 목표예요(D1).
