## 표기

| 항목 | 뜻 |
| --- | --- |
| 수용 여부 | 수용 = 11.16 회의에서 합의로 기록 / 보류 = 정모님 검토 대기, 추천안을 잠정값으로 씀 / 미검토 = 회의에서 다루지 않아 설계를 이어 가려고 둔 값. 요구사항 정의서와 같은 표기예요. |
| 릴리스 | 1차 = 11.18(수) 1차 MVP / 2차 = 목요일 이후 최종 MVP / 범위 밖 = 이번에 하지 않음. 회의록 '밀리면 빼는 순서'의 것은 1차로 두고 비고에 '밀리면 뺌(Could)'이라고 적었어요. |
| 역할 | 편집자, 작가, 디자이너, 보기 전용. ○ 쓸 수 있음, △ 보기만, × 없음, ? 결정 전(보기 전용, D8) |
| 화면 ID | 영역 약자 2자 + 번호 2자리. ST 시작, HM 편집자 홈, JN 링크로 들어오기, WS 작업 공간, DV 개발용. 한 번 쓴 ID는 화면이 없어져도 다시 쓰지 않아요. |
| 그 밖의 번호 | SC- 시나리오, TK- 과업, I- 정보, N- 내비게이션, SR- 검색, F- 필터, TG- 분류·태그·표시, L- 레이블, G- 제스처, SL- 선택, S- 상태, CS- 컴포넌트 상태, X- 상태 변화. FR-, NFR-, Q-는 요구사항 정의서의 번호예요. |
| 근거 | 11.16 회의 항목 번호: A1~A11 용어, B1~B10 화면 영역, C1~C12 경계를 넘는 동작, P1~P6 지면·편집기 경계, M1~M8 1차 MVP·저장소. D1~D8과 T1~T5는 11.14 요청서의 결정 항목과 기술 확인이에요. |
