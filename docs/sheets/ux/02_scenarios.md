# UX 설계서 · 사용자 시나리오

> 원본은 Google 시트 'UX 설계서'의 '사용자 시나리오' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

사용자 시나리오는 페르소나가 어떤 상황에서 무엇을 하려는지를 글로 풀어 쓰는 문서라 표로 정리했어요(행위자, 상황, 동기, 의도, 행동, 결과). 흐름을 그림으로 그린 것은 태스크 플로우와 최종 이용 흐름이고 FigJam에 있어요. 페르소나는 기획서 v2.0의 공통 페르소나 두 명(편집자, 작가)과 11.18에 더한 디자이너이고, 은미님 11.14 시나리오(작가 A, 편집자 B)를 이어 써요. 인터뷰 전이라 페르소나와 결과는 가설이에요.
