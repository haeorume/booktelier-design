## 이름 붙이는 규칙

1. 한 가지에는 이름 하나만 쓴다. 화면, 문서, 코드 이름을 이 표에서 맞춘다.

2. AI가 낸 것은 '적용'과 '무시', 사람이 보낸 것은 '수락'과 '거절'로 나눠 부른다.

3. 상태는 '~됨'이나 '~ 중'으로 끝낸다. 동작은 버튼에 쓰는 짧은 말로 적는다.

## 4. 역할과 종류는 색만으로 구분하지 않고 글자를 함께 쓴다.
