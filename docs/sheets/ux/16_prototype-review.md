# UX 설계서 · 프로토타입 검토

> 원본은 Google 시트 'UX 설계서'의 '프로토타입 검토' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

오름님이 만든 HTML 프로토타입에서 무엇을 가져오고 무엇을 뺄지 정한 표예요. PR-01~24는 11.17 판을 11.18에 본 것이고, v0.4(11.20)에서 새 판을 최종 MVP 기준으로 다시 봤어요. 판단은 최종 MVP 간극 논의판(rev 7)에서 정한 것이고, 바뀐 줄은 판단 칸에 'v0.4'를 붙였어요(PR-15·16·17·24). 새 판에서 새로 본 것은 PR-25~37이에요. 기준은 세 가지예요. ① 셋(편집자, 작가, 디자이너)이 각자 브라우저에서 같은 종이책 판형 지면 하나를 함께 본다, ② 최종 MVP 범위와 요구사항 정의서 v0.4, ③ 접근성과 UI 실무 기준(WCAG 2.2, WAI-ARIA APG, 닐슨 휴리스틱). 11.18 검토 때 대비는 WCAG 공식으로 계산했고, 화면은 1440px에서 확인했어요. '가져올 것 n'과 'HTML 표 n'은 논의판의 번호예요. 오름님께 드릴 피드백은 이 표를 바탕으로 해요.
