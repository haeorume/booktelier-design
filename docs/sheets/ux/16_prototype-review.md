# UX 설계서 · 프로토타입 검토

> 원본은 Google 시트 'UX 설계서'의 '프로토타입 검토' 탭이에요. `scripts/sheets_to_md.py`가 만든 파일이라 직접 고치지 않아요.

오름님이 11.17에 만든 HTML 프로토타입에서 무엇을 가져오고 무엇을 민지 정한 표예요(11.18). 기준은 세 가지예요. ① 셋(편집자, 작가, 디자이너)이 같은 ePub 지면 하나에서 작업한다(11.18 결정), ② 1차 데모 13단계와 요구사항 정의서 범위, ③ 접근성과 UI 실무 기준(WCAG 2.2, WAI-ARIA APG, 닐슨 휴리스틱). 대비는 WCAG 공식으로 계산했고, 화면은 1440px에서 확인했어요. 오름님께 드릴 피드백은 이 표를 바탕으로 해요(WBS 1.16).
