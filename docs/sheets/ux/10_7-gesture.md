## 7. 인터랙션: 제스처

사용자가 손으로 하는 동작과 그 결과예요. 기준 환경은 데스크톱 웹 브라우저, 마우스와 키보드예요. 마우스로 하는 일은 모두 키보드로도 할 수 있게 적었어요. 터치 화면은 범위 밖이에요.

| 번호 | 제스처 | 대상 | 결과 | 화면 반응 | 키보드로 하는 방법 | 릴리스 | 수용 여부 | 근거 | 비고 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| G-01 | 클릭 | 버튼, 탭, 장 항목, 책 카드, 필터 | 그 동작을 실행하거나 그 화면으로 간다 | 누름 표시 뒤 결과가 보인다 | Tab으로 옮기고 Enter 또는 Space | 1차 | 미검토 | Material: 제스처(이동, 실행) |  |
| G-02 | 클릭 | 지면의 밑줄 | 그 AI 제안 카드가 선택된다 | 밑줄과 카드가 함께 강조되고, 패널이 그 카드로 움직인다 | 커서가 밑줄 안에 있을 때 여는 단축키는 나중 | 1차 | 미검토 | B4, B5, Grammarly 관찰 |  |
| G-03 | 클릭 | AI 제안 카드, 의견 카드, 수정 제안 카드 | 카드가 선택되고 지면이 그 자리로 움직인다 | 카드 테두리와 지면의 그 자리가 강조된다 | 카드에 포커스를 두고 Enter | 1차 | 미검토 | B5, B6 |  |
| G-04 | 올려놓기 | 밑줄 | 바뀌는 것 없음 | 밑줄이 강조되고 종류 이름이 보인다 | 카드에서 같은 내용을 본다 | 2차 | 미검토 | Grammarly 관찰 | 올려놓아야만 보이는 정보는 두지 않는다 |
| G-05 | 올려놓기 | 카드, 버튼, 장 항목, 책 카드 | 바뀌는 것 없음 | 누를 수 있다는 표시 | 포커스 표시가 같은 구실을 한다 | 1차 | 미검토 | Material: 상태(올려놓음) |  |
| G-06 | 누른 채 끌기 | 지면의 글자 | 글자 범위가 선택된다 | 선택한 자리가 표시되고 선택 메뉴가 뜬다 | Shift + 화살표 | 1차 | 미검토 | Material: 선택(글자), A4 |  |
| G-07 | 두 번 클릭 | 지면의 글자 | 낱말이 선택된다 | 브라우저 기본 동작 |  | 1차 | 미검토 |  |  |
| G-08 | 글자 입력 | 지면 본문 (작가) | 원고가 바뀐다. 1~2초 멈추면 바뀐 문단을 분석한다 | 글자는 바로 보이고, 분석하는 동안 AI 상태에 표시된다 |  | 1차 | 보류 | C1 | 멈추는 시간과 보내는 범위는 정모님 |
| G-09 | 글자 입력 | 입력 칸 (책 제목, 이름, 보내는 문구, 답글) | 값이 들어간다 | 값이 비면 실행 버튼이 비활성 | 한 줄 입력 칸은 Enter로 실행 | 1차 | 미검토 |  |  |
| G-10 | 스크롤 | 지면, 검토 패널, 장 목록 | 영역마다 따로 움직인다 |  | Page Up, Page Down, 화살표 | 1차 | 미검토 |  |  |
| G-11 | 실행 취소 | 지면 | 마지막 변경을 되돌린다. AI 제안 적용을 되돌리면 그 제안은 대기로 돌아온다 | 원고와 카드가 함께 되돌아간다 | Ctrl/Cmd + Z | 1차 | 보류 | C4 |  |
| G-12 | 닫기 | 창, 선택 메뉴 | 닫히고 열기 전 자리로 포커스가 돌아간다 |  | Esc | 1차 | 미검토 |  |  |
| G-13 | 복사 | 공유 창의 링크 복사 버튼 | 링크가 클립보드에 들어간다 | 버튼이 잠깐 '복사됨'으로 바뀐다 | Enter | 1차 | 미검토 | 퍼널 3 |  |
| G-14 | 붙여넣기 | 지면 본문 (작가) | 붙여 넣은 글이 원고에 들어가고 분석 대상이 된다 |  | Ctrl/Cmd + V | 1차 | 미검토 | C1 |  |
| G-15 | 쓰지 않는 제스처 | 오른쪽 클릭 메뉴, 끌어서 옮기기, 터치(누르기, 길게 누르기, 쓸기, 벌리기) | 1차 MVP에서는 따로 만들지 않는다 | 오른쪽 클릭은 브라우저 기본 메뉴 그대로 |  | 범위 밖 | 보류 |  | 장 순서 바꾸기와 터치 화면은 1차 MVP 밖 |
