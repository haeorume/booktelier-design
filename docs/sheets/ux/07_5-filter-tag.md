## 5. 필터·태그 설계

목록을 거르는 필터(F-), 시스템이 붙이는 분류와 표시, 사용자가 붙이는 태그(TG-)를 한 표에 모았어요. 1차 MVP에서 사용자가 직접 붙이는 태그는 없어요.

## 거르기 규칙

| 경우 | 규칙 |
| --- | --- |
| 같은 필터 안에서 여러 값을 고르면 | 고른 값 가운데 하나라도 맞는 것을 보여 준다 |
| 필터를 두 개 이상 쓰면 | 모두 맞는 것만 보여 준다 |
| 필터를 눌렀을 때 | 화면을 옮기지 않고 목록만 바뀐다 |
| 장을 옮기면 | 필터는 그대로 둔다 (미검토) |
