일을 마쳤으면 보고하고 멈춰요. 커밋하지 않아요.

1. `node scripts/check-all.mjs`를 돌려요. 화면을 바꿨으면 `cd web && npm run test:e2e`도 돌려요.
2. `node scripts/progress.mjs`를 돌려요.
3. 아래 모양 그대로 적어요(CLAUDE.md 5번). 검사 결과는 명령과 결과를 고치지 말고 붙여요.

```
## 보고: F? <이름> — <조각>
- 만든 것
- 바뀐 계약(경로·모양, A-xx)
- 확인하는 방법(사람이 눌러 볼 순서, 띄울 명령, 브라우저 몇 개로)
- 검사 결과: check-all, e2e (명령과 결과 그대로. DB 테스트를 돌렸는지)
- 진행: progress 결과 중 이 F 부분
- 확인한 QA·S와 결과(통과 / 일부 / 안 됨 / 못 봄, 이유)
- 남긴 이벤트
- 마이그레이션(있으면 무엇을 바꾸는지)
- 문서와 다르게 한 것(없으면 '없음')
- 다음 할 것
```
