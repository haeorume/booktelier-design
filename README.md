# Booktelier(북틀리에)

편집자·작가·디자이너가 같은 책 모양 지면에서 함께 책을 만드는 작업 공간이에요.
1차 MVP는 `web/`(Next.js) 화면이 예시 데이터로 돌면서, **한 브라우저에서 역할을 바꿔** 데모 플로우 13단계를 끝까지 보여 줘요.
서버, DB, 실제 AI 호출, 로그인은 아직 없어요(`docs/DECISIONS.md` D-06).

저장소 안내(어디에 무엇이 있나)는 `AGENTS.md`, 작업 계획은 `docs/PLAN.md`를 보세요.

## 실행

Node.js 22 이상이 필요해요.

```bash
cd web
npm install
npm run dev        # http://localhost:3000
```

배포용으로 빌드해서 띄우려면:

```bash
cd web
npm run build
npm run start
```

### 환경 변수

꼭 넣어야 하는 값은 없어요. API 키도 필요 없어요.

| 이름 | 값 | 뜻 |
| --- | --- | --- |
| `NEXT_PUBLIC_DEV_BAR` | `off` | 화면 위 노란 개발용 막대(역할·패널 배치 전환)를 숨겨요. 넣지 않으면 보여요. 빌드할 때 정해져요 |

### 배포(Vercel)

- 프로젝트의 Root Directory를 `web`으로 둬요. 빌드 명령과 출력 폴더는 Next.js 기본값 그대로예요.
- 환경 변수는 넣지 않아도 돼요. 데모에는 개발용 막대가 있어야 해서 `NEXT_PUBLIC_DEV_BAR`도 비워 둬요.

## 검사와 테스트

```bash
cd web
npm run check          # lint + 타입 검사 + 단위 테스트 + 불변 규칙(R1~R10)
npx playwright install chromium   # e2e를 처음 돌릴 때 한 번
npm run test:e2e       # Playwright. 개발 서버를 스스로 띄워요
```

- 데모 1~13단계를 한 번에 누르는 테스트는 `web/e2e/demo-flow.spec.ts`예요. 콘솔 오류가 없는지, 끝에서 퍼널 도달 수가 모두 1인지도 봐요.
- 실패한 테스트의 결과(trace)는 시스템 임시 폴더의 `booktelier-playwright`에 남아요. `web/` 안에 쓰면 개발 서버가 다시 빌드해서 테스트가 흔들려 밖에 둬요.

## 데모 13단계 보는 법

빈 브라우저(시크릿 창이 편해요)에서 http://localhost:3000 을 열어요. 화면 위 노란 **개발용 막대**로 역할을 바꿔요. 역할을 바꿔도 주소는 그대로예요.

| 단계 | 역할 | 할 일 |
| --- | --- | --- |
| 1·2 | 편집자 | 책 제목을 넣고 템플릿을 골라 '만들기' |
| 3 | 편집자 | 상단 바 '공유'에서 작가 링크와 디자이너 링크를 각각 '링크 복사' |
| 4·5 | 작가 | 복사한 작가 링크를 같은 브라우저 주소창에 붙여 열고, 이름을 넣어 '들어가기' |
| 6 | 작가 | 지면 둘째 문단 끝에 글을 더하고 잠시 멈춤 → 밑줄과 카드가 뜨면 '적용' |
| 7 | 작가 | 장 머리의 '검토 요청' |
| 8 | 편집자 | 막대에서 '편집자' → 경로의 '편집자 홈' → 책 카드 → '장 검토' |
| 9 | 편집자 | '몇일' 카드에서 '보내기' → '수정 제안'으로 문구를 다듬어 보내기 |
| 10 | 작가 | 막대에서 '작가' → '함께 봄' 탭의 수정 제안 '수락' |
| 11 | 편집자 | 막대에서 '편집자' → 상단 바 '검토본'에 이름을 넣어 '검토본 저장' |
| 12 | 디자이너 | 복사한 디자이너 링크를 열고 이름을 넣어 '들어가기' |
| 13 | 디자이너 | 상단 바 '조판 설정'에서 행간이나 여백을 바꿈 |

끝난 뒤 http://localhost:3000/dev/events 를 열면 13단계마다 도달 수와 이탈 수가 표로 보여요. 사용자 화면에는 이 주소로 가는 링크가 없어요.

개발용 막대의 '패널: 하나씩 / 나란히'는 검토 패널과 조판 설정을 번갈아 열지, 함께 열지를 바꿔요(D-10).

## 1차의 한계

- **저장은 그 브라우저 안(localStorage)에만** 돼요. 공유 링크를 다른 컴퓨터나 다른 브라우저에서 열면 '링크를 쓸 수 없어요'가 나와요. 데모는 한 브라우저에서 막대로 역할을 바꿔 봐요.
- **AI 제안은 예시 데이터**예요. 실시간 교정은 둘째 문단을 고칠 때만 제안 2개가 뜨고, 장 검토는 늘 같은 5개를 돌려줘요.
- 새 책은 늘 예시 원고 1장으로 시작해요.
- 실시간 공동 작업은 없어요. 상단 바의 참여자 표시는 이 책에 들어온 사람의 목록이에요.
- 처음부터 다시 보려면 브라우저 저장소를 지우거나 시크릿 창을 새로 열어요.
